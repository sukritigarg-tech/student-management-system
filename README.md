
# Student Management System

## About the Project
A menu-driven Student Management System developed using Python.
It allows users to manage student records through a simple
command-line interface.

## Features
- Add new student records
- View all registered students
- Search students using roll number
- Calculate average marks
- Store records permanently in a text file
- Handle invalid inputs
- Prevent duplicate roll numbers

## Technologies Used
- Python 3
- File Handling
- Lists and Dictionaries
- Functions
- Loops and Conditional Statements
- Exception Handling

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python student_management.py

## How to Use

1. Select an option from the main menu.
2. Enter student details when adding a student.
3. View or search student records.
4. Calculate the average marks.
5. Select Exit to close the program.
